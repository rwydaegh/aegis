- [2026-04-13] feature-agent: Shipped viewer bug fixes and frontend performance improvements. (1) **Basestations stale cache key**: `_handle_basestations_compute` and `_handle_basestations_compute_mimo` used `cache.get("body")` (legacy backward-compat alias) instead of `cache.get("bodies", {}).get(body_name)`. This meant base station dosimetry always used the default phantom, ignoring `body_name` parameter. Now uses the same `bodies` dict lookup as all other compute routes. (2) **Flask secret key**: Replaced hardcoded fallback `"dev-secret-key-change-me"` with `os.urandom(32)` to prevent session cookie forgery when `FLASK_SECRET_KEY` env var is unset. (3) **GLB phantom caching**: Added `conditional=True, max_age=3600` to `send_file` for GLB phantoms (10+ MB files re-downloaded every page load), plus path containment check via `is_relative_to`. (4) **Coverage heatmap cache collision**: Cache key was `${byteLength}-${siteCount}` which collides for same-sized datasets. Switched to reference identity check on the Float32Array buffer. (5) **IcosahedronGeometry detail 8 -> 5**: Radiation pattern meshes had 655K vertices (detail=8). Reduced to 10K vertices (detail=5), capped at 6. Visually identical, 65x fewer vertices. AntennaArray was ignoring config and hardcoding detail=8. (6) **Per-frame Vector3 allocations**: FollowCamera and usePhysics created `new THREE.Vector3()` every animation frame. Moved to refs to eliminate GC pressure. (7) **React.memo on scene components**: Wrapped PanelAntenna, AntennaArray, SmartphoneModel in `memo()` to prevent unnecessary re-renders in base station scenes with hundreds of antennas. (8) **Tiles count caching**: `/api/config` was running `glob("*.glb")` filesystem scan on every call. Now cached after first computation. All 2328 tests pass, TS compiles clean, frontend builds.
