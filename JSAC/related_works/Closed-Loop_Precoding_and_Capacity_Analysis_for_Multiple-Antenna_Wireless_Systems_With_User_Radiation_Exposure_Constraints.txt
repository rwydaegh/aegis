   Today’s single transmit antenna systems deal with the SAR
constraints using a power back-off approach. The general idea
is to design the signaling algorithms using only a transmit
power constraint, check to see if the final design satisfies the
SAR regulations, and reduce the transmit power if necessary.
This power reduction approach works because the FCC requires
that the worst-case SAR reading of each portable device satisfy
the SAR threshold. If we map the power back-off method to a
multiple antenna transmitter, the worst-case SAR is given by
