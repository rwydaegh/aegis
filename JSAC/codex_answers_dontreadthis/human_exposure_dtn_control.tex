\begin{abstract}
This note extracts the mathematical core needed for a body-aware digital
twin network paper.  AEGIS turns each body state into Hermitian positive
semidefinite exposure operators.  The network controller sees these
operators as constraints on the transmit covariance.  We collect the useful
facts: local absorbed-power-density operators, incident-field grid
operators, multi-stream superposition, pose-robust Loewner envelopes, a
linear thermal state model, and a primal-dual closed-loop controller.  The
emphasis is implementation-facing.  Each theorem either gives a certificate
that a candidate precoder is safe, a margin that absorbs twin error, or a
dual variable with a direct interpretation as an exposure congestion price.
\end{abstract}

% ============================================================
\section{Objects in the control loop}
% ============================================================

Let a base station or a cooperating set of base stations have $M$ complex
transmit degrees of freedom.  The downlink signal is
\begin{equation}
  \xx(t)=\sum_{k\in\Users}\ww_k(t)s_k(t),
  \qquad
  \mathbb E[s_k s_\ell^*]=\delta_{k\ell},
\end{equation}
with stream precoders $\ww_k\in\Complex^M$.  Define the stream covariance
and total covariance
\begin{equation}
  \W_k=\ww_k\ww_k^H,\qquad
  \W=\sum_{k\in\Users}\W_k\succeq0,\qquad
  \tr\W=\sum_k\|\ww_k\|^2.
\end{equation}

The physical scene contains bodies $u\in\Bodies$, including served users
and non-served bystanders.  The body digital twin state is
\begin{equation}
  \xi_u=(p_u,R_u,\theta_u,m_u,\tau_u,\gamma_u,\ldots)\in\States_u,
\end{equation}
where $p_u,R_u$ are rigid pose, $\theta_u$ is articulated pose,
$m_u$ is body/phantom identity or shape, $\tau_u$ is tissue state, and
$\gamma_u$ is a grip or device-body geometry state when relevant.  The
state is not assumed exact.  At time $t$ the controller holds an uncertainty
set $\Xi_u(t)\subset\States_u$.

\begin{remark}[What is twinned]
The useful twin state is not only the radio channel.  It is the minimal
state needed to evaluate exposure constraints: body occupancy, body
surface, pose, tissue, device-body geometry, and the propagation paths
from transmit degrees of freedom to each body surface.  The channel
$\hh_k$ is only the signal branch of this state.
\end{remark}

\begin{definition}[Transmit-to-path control map]\label{def:B}
For body $u$, let $\B_u\in\Complex^{N_u\times M}$ map the network's
transmit variables to complex amplitudes on the $N_u$ paths incident on
that body.  The $n$-th row of $\B_u$ is the array, port, or beam response
that controls path $n$.  A binary element-to-path dispatch matrix $J_u$ is
the special case in which each path is tagged to exactly one transmit
element:
\begin{equation}
  (J_u)_{nm}=1\{j_u(n)=m\}.
\end{equation}
In calibrated-array or codebook models $\B_u$ is generally dense, e.g.
$(\B_u)_{nm}=\alpha_n a_m(\Omega^{\mathrm{AoD}}_n)$ or
$(\B_u)_{nb}=\alpha_n g_b(\Omega_n)$.
\end{definition}

\begin{remark}[Body state is insufficient]
The body state $\xi_u$ determines how an incident path family couples to
the body.  It does not determine which transmit weights create those path
amplitudes.  Exposure estimation therefore requires the triple
\[
  \text{body state }\xi_u,\qquad
  \text{path state }\mathcal P_u,\qquad
  \text{control map }\B_u.
\]
AEGIS ray tracing provides this through path data and element indices.  A
real deployment would estimate $\B_u$ from channel sounding, calibrated
array responses, or beam/codebook measurements.
\end{remark}

\section{Local body exposure operators}
% ============================================================

For body $u$ at state $\xi_u$, let
$\Sigma_u(\xi_u)$ be its surface and
$\Gtil_u(\rr;\xi_u)\in\Complex^{3\times M}$ be the Fresnel-filtered,
depth-coupled body-surface channel of the monograph.  The coherent
absorbed power density from one precoder $\ww$ is
\begin{equation}
  S_{\mathrm{ab}}^{(u)}(\rr;\ww,\xi_u)=
  \|\Gtil_u(\rr;\xi_u)\ww\|^2.
\end{equation}

At FR2 the relevant compliance object is local spatially averaged APD,
not only whole-body absorbed power.  Let
$\mathcal P_{u,i}(\xi_u)\subset\Sigma_u(\xi_u)$ be a surface patch, for
example a 4 cm$^2$ ICNIRP averaging patch centered at mesh index $i$.

\begin{definition}[Local APD operator]
The local APD operator for body $u$ and patch $i\in\Patches_u$ is
\begin{equation}\label{eq:Qloc}
  \Q_{u,i}(\xi_u)=
  \frac{1}{|\mathcal P_{u,i}|}
  \int_{\mathcal P_{u,i}(\xi_u)}
  \Gtil_u(\rr;\xi_u)^H\Gtil_u(\rr;\xi_u)\,\diff A
  \in\Complex^{M\times M}.
\end{equation}
It is Hermitian PSD and has units such that
$\ww^H\Q_{u,i}\ww$ is W/m$^2$.
\end{definition}

\begin{definition}[Whole-body absorbed-power operator]
The whole-body operator is
\begin{equation}\label{eq:Qwb}
  \Q^{\mathrm{wb}}_u(\xi_u)=
  \int_{\Sigma_u(\xi_u)}
  \Gtil_u(\rr;\xi_u)^H\Gtil_u(\rr;\xi_u)\,\diff A,
\end{equation}
so $\ww^H\Q_u^{\mathrm{wb}}\ww$ is absorbed power in watts.
\end{definition}

\begin{proposition}[Multi-stream exposure superposition]\label{prop:streams}
For independent streams, the expected local APD on patch $(u,i)$ is
\begin{equation}\label{eq:stream-superposition}
  \mathbb E[\APD_{u,i}]
  =\sum_{k\in\Users}\ww_k^H\Q_{u,i}(\xi_u)\ww_k
  =\tr\!\bigl(\Q_{u,i}(\xi_u)\W\bigr).
\end{equation}
The same identity holds for whole-body absorbed power with
$\Q_{u,i}$ replaced by $\Q_u^{\mathrm{wb}}$.
\end{proposition}

\begin{proof}
At a surface point,
$\Gtil\xx=\sum_k\Gtil\ww_k s_k$.  Expanding the squared norm and taking
expectation over uncorrelated unit-power data symbols removes all
cross-stream terms.  Integrating over the patch gives the first equality.
The second equality is cyclicity of trace.
\end{proof}

\begin{remark}[Mesh implementation]
On a mesh, \eqref{eq:Qloc} is a weighted sum of rank-at-most-three
triangle operators:
\[
  \Q_{u,i}=\sum_j W^{(u)}_{ij}\,
  \Gtil_u(\rr_j)^H\Gtil_u(\rr_j),
\]
where $W^{(u)}$ is the sparse spatial averaging matrix.  Once the
per-triangle matrices are available, finding the active patch for a
candidate covariance is one sparse matrix-vector product.
\end{remark}

\section{Incident-field grid operators}
% ============================================================

Some jurisdictions regulate incident electric field or incident power
density on public-accessible points rather than absorbed power on bodies.
This is a different constraint family and should be kept algebraically
separate.

Let $g\in\mathcal G$ index a regulatory grid point, balcony point, or
public-accessible sample point.  Let
$\mathbf G_{\mathrm{inc},g}\in\Complex^{3\times M}$ map transmit precoder
to the incident free-space electric field at that point.  Define
\begin{equation}\label{eq:Rgrid}
  \R_g=\frac{1}{2Z_0}\mathbf G_{\mathrm{inc},g}^H
  \mathbf G_{\mathrm{inc},g},
  \qquad
  S_{\mathrm{inc}}^{(g)}(\W)=\tr(\R_g\W).
\end{equation}
If the legal constraint is expressed in field strength
$E_g\le E_{\max,g}$, the equivalent incident power-density threshold in
free space is
\begin{equation}
  L_g^{\mathrm{inc}}=\frac{E_{\max,g}^2}{2Z_0}.
\end{equation}

\begin{remark}[Body and grid constraints are not interchangeable]
The absorbed-power relation
$\Sab\approx T(\theta)\Sinc[\hat n\cdot(-\hat k)]_+$ converts incident
flux to absorption only after specifying a body surface, normal, tissue,
polarisation, and incidence direction.  A regulatory grid constraint
therefore remains a grid constraint.  A body APD certificate does not by
itself certify a jurisdictional incident-field ordinance, and a grid
certificate does not certify local APD on a body.
\end{remark}

% ============================================================
\section{One operator language for all instantaneous constraints}
% ============================================================

The constraints above can be unified.  Let $c\in\Constraints(t)$ index
one active or candidate constraint at time $t$.  Each constraint has
a PSD matrix $\A_c(t)$ and a threshold $L_c(t)$:
\begin{equation}\label{eq:constraint-dict}
\begin{array}{lll}
\text{local APD:} & \A_c=\Q_{u,i}(\xi_u), & L_c=L_{\APD},\\[0.25em]
\text{whole body:} & \A_c=\Q_u^{\mathrm{wb}}(\xi_u), & L_c=P_{\mathrm{abs},u}^{\max},\\[0.25em]
\text{incident grid:} & \A_c=\R_g, & L_c=L_g^{\mathrm{inc}},\\[0.25em]
\text{power:} & \A_c=\Id, & L_c=P.
\end{array}
\end{equation}
All instantaneous safety constraints read
\begin{equation}\label{eq:linear-W-constraint}
  \tr(\A_c(t)\W(t))\le L_c(t),
  \qquad c\in\Constraints(t).
\end{equation}

\begin{proposition}[Convexity in covariance]\label{prop:convex}
For fixed twin state, the feasible covariance set
\begin{equation}
  \mathcal F(t)=
  \{\W\succeq0:\tr(\A_c(t)\W)\le L_c(t)\ \forall c\in\Constraints(t)\}
\end{equation}
is closed and convex.  It remains convex after adding per-antenna power
constraints $\W_{mm}\le P_m$ and block power constraints
$\tr(\Pi_o\W)\le P_o$.
\end{proposition}

\begin{proof}
Each inequality is affine in $\W$, and the PSD cone is convex and closed.
\end{proof}

\begin{remark}[Where nonconvexity enters]
The safety side is convex in transmit covariance.  Nonconvexity enters
through rank constraints $\W_k=\ww_k\ww_k^H$ and through the multi-user
sum-rate objective.  This is why WMMSE, successive convex approximation,
or primal-dual beam updates are natural: every inner safety projection is
an intersection of PSD half-spaces.
\end{remark}

\section{Pose-robust envelopes}
% ============================================================

The controller rarely knows $\xi_u$ exactly.  A compliance statement must
therefore quantify the state set over which it is valid.

\begin{definition}[Loewner envelope]
Given a family of PSD matrices
$\{\A(\xi):\xi\in\Xi\}$, a Loewner envelope is any PSD matrix $\Abar$
such that
\begin{equation}
  \Abar\succeq \A(\xi)\qquad\forall\xi\in\Xi.
\end{equation}
\end{definition}

\begin{proposition}[Robust certificate]\label{prop:robust-certificate}
If $\Abar_c(t)\succeq \A_c(\xi,t)$ for all admissible twin states
$\xi\in\Xi(t)$, then
\begin{equation}\label{eq:robust-cert}
  \tr(\Abar_c(t)\W(t))\le L_c
  \quad\Longrightarrow\quad
  \tr(\A_c(\xi,t)\W(t))\le L_c
  \ \ \forall\xi\in\Xi(t).
\end{equation}
\end{proposition}

\begin{proof}
$\Abar_c-\A_c(\xi)\succeq0$ implies
$\tr((\Abar_c-\A_c(\xi))\W)\ge0$ for every $\W\succeq0$.
\end{proof}

\begin{definition}[Finite dictionary envelope]
For a finite pose or occupancy dictionary
$\Xi=\{\xi_1,\ldots,\xi_T\}$, a minimum-trace envelope is any solution of
\begin{equation}\label{eq:envelope-sdp}
  \min_{\Abar\succeq0}\ \tr(\Abar)
  \quad\text{s.t.}\quad
  \Abar\succeq \A(\xi_j),\quad j=1,\ldots,T.
\end{equation}
\end{definition}

\begin{remark}[Cheap safe envelopes]
Two safe scalar envelopes are
\begin{equation}
  \Abar_{\lambda}=\bigl(\max_j\lambda_{\max}(\A(\xi_j))\bigr)\Id,
  \qquad
  \Abar_{\tr}=\bigl(\max_j\tr(\A(\xi_j))\bigr)\Id.
\end{equation}
The matrix $(\max_j\tr\A(\xi_j))\Id/M$ is not safe in general: it may
fail to dominate a rank-one matrix whose top eigenvalue equals its trace.
\end{remark}

\begin{proposition}[Envelope slack bound]\label{prop:slack}
Let $\Abar$ be an envelope and define its worst directional slack
\begin{equation}
  \epsilon_{\Abar}
  =\sup_{\xi\in\Xi}\|\Abar-\A(\xi)\|_2.
\end{equation}
For any $\W\succeq0$ with $\tr\W\le P$,
\begin{equation}
  0\le \tr(\Abar\W)-\sup_{\xi\in\Xi}\tr(\A(\xi)\W)
  \le \epsilon_{\Abar}P.
\end{equation}
\end{proposition}

\begin{proof}
The lower bound is the envelope property.  For the upper bound, for every
$\xi$,
$\tr((\Abar-\A(\xi))\W)\le\|\Abar-\A(\xi)\|_2\tr\W\le\epsilon_{\Abar}P$.
Taking the supremum over $\xi$ preserves the bound.
\end{proof}

\section{Thermal or dose state}
% ============================================================

Instantaneous APD is conservative relative to tissue heating.  A DTN can
carry the exposure state over time.  The exact thermal model may be a
Pennes BHTE surrogate, a first-order exponential filter, or a regulatory
time-average.  The controller only needs a positive linear state update.

\begin{definition}[Linear exposure state]
For body $u$ and patch $i$, define a scalar state $z_{u,i}[n]\ge0$ with
update
\begin{equation}\label{eq:thermal-state}
  z_{u,i}[n+1]
  =a_{u,i}z_{u,i}[n]
  +b_{u,i}\,\tr\!\bigl(\Q_{u,i}(\xi_u[n])\W[n]\bigr)
  +d_{u,i}[n],
\end{equation}
where $0\le a_{u,i}<1$, $b_{u,i}\ge0$, and $d_{u,i}$ captures ambient or
metabolic baseline.  The safety condition is
\begin{equation}
  z_{u,i}[n]\le z_{u,i}^{\max}.
\end{equation}
\end{definition}

\begin{remark}[Interpretation]
If $z$ is a running APD average over a window $T$, then
$a\approx1-\Delta t/T$ and $b\approx\Delta t/T$.  If $z$ is a thermal
rise surrogate, then $a=e^{-\Delta t/\tau}$ and $b$ is the patch thermal
impulse gain.
\end{remark}

\begin{proposition}[One-step thermal safety constraint]\label{prop:one-step}
For a fixed state estimate and fixed twin state, the condition
$z_{u,i}[n+1]\le z_{u,i}^{\max}$ is equivalent to the affine covariance
constraint
\begin{equation}\label{eq:thermal-affine}
  \tr\!\bigl(\Q_{u,i}(\xi_u[n])\W[n]\bigr)
  \le
  \frac{z_{u,i}^{\max}-a_{u,i}z_{u,i}[n]-d_{u,i}[n]}{b_{u,i}},
\end{equation}
when $b_{u,i}>0$.
\end{proposition}

\begin{proof}
Rearrange \eqref{eq:thermal-state}.
\end{proof}

\begin{corollary}[Robust thermal step]
If $\Qbar_{u,i}[n]\succeq\Q_{u,i}(\xi)$ for every
$\xi\in\Xi_u[n]$, then replacing $\Q_{u,i}$ by $\Qbar_{u,i}$ in
\eqref{eq:thermal-affine} guarantees the one-step thermal constraint for
all admissible poses.
\end{corollary}

\section{Closed-loop optimization}
% ============================================================

A compact model-predictive controller over horizon $H$ is
\begin{equation}\label{eq:mpc}
\begin{aligned}
\max_{\{\ww_k[n]\}_{n=0}^{H-1}}\quad&
  \sum_{n=0}^{H-1}\gamma^n U_n(\{\ww_k[n]\})\\
\text{s.t.}\quad&
  \tr(\A_c[n]\W[n])\le L_c[n],
  \qquad c\in\Constraints[n],\\
& z_{u,i}[n+1]=a_{u,i}z_{u,i}[n]
  +b_{u,i}\tr(\Q_{u,i}[n]\W[n])+d_{u,i}[n],\\
& z_{u,i}[n+1]\le z_{u,i}^{\max},
  \qquad u\in\Bodies,\ i\in\Patches_u,\\
& \W[n]=\sum_k\ww_k[n]\ww_k[n]^H.
\end{aligned}
\end{equation}
Here $U_n$ can be sum-rate, weighted sum-rate, proportional fairness,
XR semantic utility, or a control-task objective.  For implementation,
\eqref{eq:mpc} is normally solved by one-step receding horizon, WMMSE
outer iterations, or primal-dual updates rather than as a monolithic
nonconvex program.

\subsection{Dual exposure prices}

Consider a convex inner covariance subproblem at one time step:
\begin{equation}\label{eq:convex-inner}
  V(L)=
  \max_{\W\succeq0}\ f(\W)
  \quad\text{s.t.}\quad
  \tr(\A_c\W)\le L_c,\quad c\in\Constraints,
\end{equation}
where $f$ is concave and differentiable.  This covers weighted signal
power, WMMSE covariance updates, and many convex surrogates of rate.

\begin{proposition}[Dual variables as exposure prices]\label{prop:prices}
Let strong duality hold for \eqref{eq:convex-inner}, and let
$\lambda_c^\star\ge0$ be the optimal multiplier of constraint $c$.
Then, wherever the value function is differentiable,
\begin{equation}\label{eq:price}
  \frac{\partial V}{\partial L_c}=\lambda_c^\star.
\end{equation}
\end{proposition}

\begin{proof}
This is the envelope theorem for a convex program with affine right-hand
sides.  Increasing $L_c$ relaxes the feasible set; the optimal Lagrange
multiplier is the marginal utility of that relaxation.
\end{proof}

\begin{remark}[Interpretation]
$\lambda_c^\star$ is an exposure congestion price.  Large prices identify
the body patch, grid point, operator budget, or thermal state that is
actually limiting the application.  This is a useful output of the DTN,
not only a solver artifact.
\end{remark}

\subsection{A practical primal-dual loop}

The one-step controller can be written as
\begin{align}
  \ww_k^{m+1}
  &\leftarrow
  \operatorname{BeamUpdate}_k
  \Bigl(\hh_1,\ldots,\hh_K,\;
  \sum_{c\in\Constraints}\lambda_c^m\A_c+\nu^m\Id\Bigr),
  \label{eq:beam-update}\\
  \lambda_c^{m+1}
  &\leftarrow
  \Bigl[\lambda_c^m+\eta_m\bigl(\tr(\A_c\W^m)-L_c\bigr)\Bigr]_+,
  \label{eq:dual-update}\\
  \nu^{m+1}
  &\leftarrow
  \Bigl[\nu^m+\eta_m\bigl(\tr(\W^m)-P\bigr)\Bigr]_+.
  \label{eq:power-update}
\end{align}
For a single stream,
\begin{equation}\label{eq:single-stream-update}
  \ww^{m+1}\propto
  \Bigl(\sum_c\lambda_c^m\A_c+\nu^m\Id\Bigr)^{-1}\hh^*.
\end{equation}
For WMMSE, the same aggregate penalty matrix appears in the per-user
linear solve.

\begin{remark}[Why all constraints sum]
All body, grid, thermal, and operator constraints enter the stationarity
condition only through the aggregate penalty
\[
  \A_{\mathrm{tot}}=\sum_c\lambda_c\A_c+\nu\Id.
\]
This is the multi-constraint generalization of the single-body ECBF
matrix $(\lambda\Q+\nu\Id)$.
\end{remark}

\section{Multi-operator aggregation}
% ============================================================

Let operators $o\in\Ops$ have disjoint transmit degrees of freedom
$M_o$ and covariances $\W^{(o)}$.  Stack them into
\begin{equation}
  \overline{\W}=\blkdiag(\W^{(1)},\ldots,\W^{(|\Ops|)}).
\end{equation}
For a body or grid constraint $c$, let $\A_c^{(o)}$ be the operator seen
from operator $o$'s transmit infrastructure.  Define
\begin{equation}
  \overline{\A}_c=
  \blkdiag(\A_c^{(1)},\ldots,\A_c^{(|\Ops|)}).
\end{equation}
The cumulative exposure constraint is
\begin{equation}\label{eq:multiop}
  \sum_{o\in\Ops}\tr(\A_c^{(o)}\W^{(o)})
  =
  \tr(\overline{\A}_c\,\overline{\W})
  \le L_c.
\end{equation}

\begin{proposition}[Cooperative aggregation is a relaxation]\label{prop:coop}
Suppose non-cooperative permits allocate fixed fractions
$\alpha_o L_c$ with $\sum_o\alpha_o=1$, while cooperative control uses
the single aggregate constraint \eqref{eq:multiop}.  Every
non-cooperative feasible allocation is feasible for the cooperative
problem.  Therefore the cooperative optimum is no worse for any common
network utility maximized over the same transmit variables.
\end{proposition}

\begin{proof}
If $\tr(\A_c^{(o)}\W^{(o)})\le\alpha_oL_c$ for each operator, summing over
$o$ gives \eqref{eq:multiop}.  The cooperative feasible set contains the
non-cooperative one.
\end{proof}

\section{Uncertainty margins and certificates}
% ============================================================

Implementation will use estimated operators
$\widehat{\A}_c$ rather than ground truth.  The controller needs a simple
margin rule.

\begin{proposition}[Operator-error safety margin]\label{prop:error-margin}
Assume
\begin{equation}
  \|\A_c-\widehat{\A}_c\|_2\le\epsilon_c
\end{equation}
for all admissible states at the current time.  If $\tr\W\le P$ and
\begin{equation}
  \tr(\widehat{\A}_c\W)\le L_c-\epsilon_cP,
\end{equation}
then $\tr(\A_c\W)\le L_c$.
\end{proposition}

\begin{proof}
$|\tr((\A_c-\widehat{\A}_c)\W)|
\le\|\A_c-\widehat{\A}_c\|_2\tr\W\le\epsilon_cP$.
\end{proof}

\begin{definition}[Auditable certificate]
At time $t$, an auditable exposure-control certificate is the tuple
\begin{equation}
  \mathcal K(t)=
  \bigl\{\Abar_c(t),L_c(t),\lambda_c(t),
  \tr(\Abar_c(t)\W(t)),\epsilon_c(t)\bigr\}_{c\in\Constraints_{\mathrm{active}}(t)}
\end{equation}
together with the body-state uncertainty sets $\Xi_u(t)$ and the transmit
covariance $\W(t)$ or its beam decomposition.
\end{definition}

\begin{remark}[Why certificates matter]
The certificate is small because only active or nearly active constraints
need to be logged.  It gives a regulator, testbed, or offline verifier the
objects needed to replay the safety claim without replaying the whole ray
tracer.
\end{remark}

\section{Path-space option}
% ============================================================

The system-level matrix formalism gives a useful implementation option.
For a fixed path set, write the local operator as
\begin{equation}\label{eq:path-option}
  \Q_{u,i}(\xi_u)=\B_u^H M_{u,i}(\xi_u)\B_u,
\end{equation}
where $\B_u$ is the transmit-to-path map of \Cref{def:B} and
$M_{u,i}$ is the path-space local APD Gram over patch $(u,i)$.  Then
\begin{equation}
  \tr(\Q_{u,i}\W)
  =\tr(M_{u,i}\,\B_u\W \B_u^H).
\end{equation}
Thus the same covariance
\begin{equation}
  C_{\mathrm{path}}=\B_u\W \B_u^H
\end{equation}
can be tested against every patch of body $u$ in path space.  This is
useful when the number of constraints is large and the path-space Grams
are sparse, low-rank, or cached across poses.

\begin{remark}[Recovering the monograph dispatch form]
The monograph's element-indexed path representation is recovered by setting
$\B_u=J_u$, giving
\[
  \Q_{u,i}=J_u^T M_{u,i}J_u.
\]
For deployment-oriented models, keep $\B_u$ primary and treat $J_u$ as a
ray-tracer bookkeeping special case.
\end{remark}

\begin{remark}[Use with caution]
The path-space form is an implementation accelerator, not necessarily the
cleanest paper narrative.  The JSAC paper should probably state the
operator result in element space, then mention that AEGIS can evaluate the
operator family via the path-space factorization.
\end{remark}

% ============================================================
\section{Coding targets}
% ============================================================

The theory above suggests the following implementation units:
\begin{enumerate}[leftmargin=1.7em,itemsep=0.25em]
  \item Build per-triangle matrices
  $\Gtil(\rr_j)^H\Gtil(\rr_j)$ for each body state.
  \item Build local APD operators using the sparse averaging matrix.
  \item Build incident-field grid operators $\R_g$ separately from body
  operators.
  \item Represent all constraints as $(\A_c,L_c,\mathrm{kind},\mathrm{id})$.
  \item Add envelope builders for finite pose dictionaries:
  cheap scalar envelope first, SDP envelope later.
  \item Add operator-error margins using \Cref{prop:error-margin}.
  \item Implement an active-set loop that alternates beam update and
  worst-constraint discovery.
  \item Log certificates $\mathcal K(t)$ for replay and plotting.
\end{enumerate}
