- [2026-04-17] code-reviewer: Focus area: physics kernels and compliance (ECBF, spatial averaging, ICNIRP limits). Found 1 real bug, fixed. **ECBF power-slack-regime fix from PR #438 is dead code; solver returns suboptimal precoder when Q is invertible.** The slack-regime branch added in commit ef268e5 (`src/aegis/coherent/ecbf.py:129-148`) is unreachable because the prior infeasibility branch (`if p_abs_inf > P_abs_max:` at line 119) fires first. When Q is invertible (eigenvalues[0] > NUMERICAL_FLOOR), `p_abs_inf` and `p_abs_asymp` compute the **same value** (both are `P * (h*^H Q^{-1} h*) / (h*^H Q^{-2} h*)`), so any case that would have triggered the slack branch already returned at line 127 with the minimum-eigenvalue direction. With h orthogonal to that direction (e.g., `Q=diag([10,1,0.001]), h=[1,1,0], P=1, P_abs_max=0.5`), the returned `x = sqrt(P)*V[:,0]` gives `|h^T x|^2 = 0` while the true slack-regime optimum gives `|h^T x|^2 = 0.55`. The existing `test_ecbf_power_slack_regime` only checked constraint satisfaction, not optimality, so it didn't catch this. **Fix**: Reordered the checks so the slack-regime branch runs before the infeasibility branch (which is now correctly only reached when Q is singular). Updated the docstring of `solve_ecbf` (`||x*||^2 <= P` rather than `= P`), updated `test_ecbf_respects_power_budget` to assert `<=` (it was asserting strict equality, which is wrong for the QCQP), strengthened `test_ecbf_power_slack_regime` to verify objective optimality (would have caught this bug), and renamed `test_infeasible_constraint_warns_and_returns_vector` to `test_tight_constraint_invertible_Q_uses_slack_regime` since under the QCQP an invertible Q is never infeasible. Also reviewed (no bugs found): `_finalize_rt_response` and zero-path handling in `routes/compute/sionna_rt.py`, `compute_exposure_operator`/`eigendecompose_Q`/`compute_rho` in `coherent/exposure_operator.py` (Hermitian PSD enforcement, ascending-vs-descending sort consistent with each caller), `level8_ecbf` (uses `x_star` directly without assuming `||x_star||^2 = P`, so the fix doesn't break sab calculation), `geometry/averaging.py` Numba inner loop. 2380 tests pass, lint + format clean.
