# Data licensing: future commercial checklist

When AEGIS moves from academic/hobby to commercial product, review these items.

## Clear for commercial use (no action needed)
- France: Etalab Open License v2.0
- Canada: OGL-Canada (Crown Copyright, permissive)
- UK: OGL v3.0
- Australia: CC-BY 4.0
- Austria: RTR public domain / open access
- Switzerland: opendata.swiss terms
- Denmark: CC0 (check anti-scraping clause)

## Needs confirmation before commercial use
- Belgium (Brussels/Flanders): no explicit license, Belgian law defaults to open
- Netherlands: no explicit license, Dutch default CC0
- Poland: PSI reuse law applies

## Problematic - action required
- **Germany (BNetzA)**: dl-de/by-2-0 license permits reuse, but BNetzA terms require written approval for commercial use. Contact BNetzA.
- **Spain (VCTEL)**: no open data license, restricted by Ley 9/2014. Commercial reuse not permitted. Either negotiate or remove from commercial product.

## Also check
- OpenCellID: CC-BY-SA 4.0 ShareAlike - implications for derivative works if we ever use OCID data
