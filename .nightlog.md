# Night log - 2026-03-25

## Agent 1 (Opus)

### What I did

**1. Validated element_index bounds in coherent channel computation**
- `field_channel.py` and `body_channel.py` now check that all element_index
  values are in [0, n_elements) before accumulation
- Previously, out-of-bounds indices caused silent data loss: `np.add.at`
  drops them silently, JAX clips them to the nearest valid index
- Now raises ValueError with clear message
- Files changed: `src/aegis/coherent/field_channel.py`, `src/aegis/coherent/body_channel.py`

**2. Hardened MIMO precoders for edge cases**
- ZF precoder: catches `LinAlgError` on singular H@H^H and falls back to MRT
  with a warning (previously crashed)
- `compute_mrt_precoder`: handles K=0 (empty user set) by returning (M_ant, 0)
  matrix (previously crashed with ZeroDivisionError)
- `compute_mimo_scene`: raises ValueError for empty scene instead of crashing
- Files changed: `src/aegis/mimo/precoders.py`, `src/aegis/mimo/compute.py`

**3. Added compliance sweep utilities**
- `power_sweep()`: compliance margin vs transmit power curve. Uses linear S_ab
  scaling to avoid re-running the engine. Returns power arrays (W and dBm),
  margin_db, compliant boolean, and p_max_compliant_w.
- `frequency_sweep()`: compliance margin vs frequency. ICNIRP limits (especially
  sinc_local ~ 55/f^0.177) change with frequency. Answers "At which frequencies
  is this exposure level compliant?"
- `compliance_heatmap()`: 2D (power x frequency) compliance map for regulatory
  analysis. Returns margin grid, compliant mask, and per-frequency max compliant
  power. Useful for identifying safe operating regions.
- Files changed: `src/aegis/compliance/__init__.py`

**4. Narrowed sionna bare except**
- `_extract_path_viz()` had `except Exception: return []` which silently
  discarded bugs. Narrowed to `except (AttributeError, TypeError, ValueError, IndexError)`.
- Files changed: `src/aegis/integration/sionna.py`

**5. Added link_budget_compliance for quick RF checks**
- Computes S_inc from free-space path loss (P * G / 4*pi*d^2), estimates
  S_ab = S_inc * T0 (using skin tissue lookup or custom T0), runs full
  ICNIRP evaluation. Returns compliance status, margin, max compliant TX
  power in both W and dBm. Useful for field engineers and initial regulatory
  assessments before running full mesh dosimetry.
- Files changed: `src/aegis/compliance/__init__.py`

**6. Added 53 new tests (775 -> 824 passing, +6%)**
- `tests/test_channel_bounds_and_sweeps.py`:
  - Field channel bounds: valid indices, negative index, too-large index,
    empty paths, single element boundary (5 tests)
  - Body channel bounds: valid indices, negative index, too-large index,
    empty paths (4 tests)
  - Power sweep: basic, monotonic margin, low/high power compliance,
    p_max consistency, custom range, invalid ref, no checks, dBm conversion (9 tests)
  - Frequency sweep: basic, low/high exposure, sinc varies with freq,
    1cm2 threshold, occupational, freq_ghz match, geomspace, multiple
    quantities, no quantities (10 tests)
  - Compliance heatmap: shape, low/high power, p_max constant for sab,
    occupational higher limits, margin decreases with power, invalid ref (7 tests)
  - MIMO precoder edge cases: singular ZF -> MRT fallback, well-conditioned ZF,
    K=0 MRT, all-zero channel, MMSE=ZF at noise=0, power normalization,
    zero Q exposure (7 tests)
  - Link budget compliance: isotropic, high/low power, gain scaling,
    inverse square law, T0 proportionality, custom T0, max power scaling,
    occupational, invalid inputs, dBm conversion (11 tests)
