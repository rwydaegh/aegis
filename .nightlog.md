## Agent 2 (Opus)

### What I did

Picked up all three suggestions from Agent 1, plus added two new features.

**1. Added `max_compliant_power()` to compliance module**
- Given a ComplianceResult at reference power P_ref, computes the maximum transmit power that keeps all ICNIRP checks passing
- Uses linear scaling: P_max = P_ref * min(limit / value) across all checks
- Works for both incoherent (0-6) and coherent (7-8) levels since S_ab is linear in P
- Files changed: `src/aegis/compliance/__init__.py`

**2. Added `DosimetryResult.scale(factor)`**
- Returns a new result with all power quantities scaled by a multiplicative factor
- Enables parameter sweeps: compute once at reference power, then scale to explore compliance boundary
- Correctly scales S_ab, P_abs, SAR, S_inc, Q, eigenvalues; preserves metadata, rho, x_star
- Files changed: `src/aegis/result.py`

**3. Added `DosimetryResult.evaluate_compliance()`**
- Runs a full ICNIRP 2020 compliance evaluation directly on a result
- Populates all available checks (sab_4cm2, sab_1cm2, sar_wb, sinc_local) from result fields
- Supports both general public and occupational scenarios
- Files changed: `src/aegis/result.py`

**4. Added `BodyMesh.from_arrays(vertices, normals=None, name="synthetic")`**
- Convenience classmethod for creating meshes from raw vertex arrays
- Auto-computes centroids, areas, and optionally normals from cross product
- Input validation for shape mismatches
- Files changed: `src/aegis/geometry/mesh.py`

**5. Added LRU cache eviction for `_G_cache` and `_fibonacci_sphere_cache`**
- `_G_cache` bounded to 16 entries (configurable via `_G_CACHE_MAX`)
- `_fibonacci_sphere_cache` bounded to 32 entries
- Evicts oldest entry when full (FIFO, since Python dicts are insertion-ordered)
- Prevents unbounded memory growth in long-running viewer sessions
- Files changed: `src/aegis/engine.py`, `src/aegis/geometry/projected_area.py`

**6. Added 41 new tests (416 -> 457 passing)**
