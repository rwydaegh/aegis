When Q is invertible (eigenvalues[0] > NUMERICAL_FLOOR), `p_abs_inf` and `p_abs_asymp` compute the **same value** (both are `P * (h*^H Q^{-1} h*) / (h*^H Q^{-2} h*)`), so any case that would have triggered the slack branch already returned at line 127 with the minimum-eigenvalue direction.
