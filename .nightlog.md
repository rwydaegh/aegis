### What I investigated but did not fix

- **JAX body_channel scatter-add "bug"**: Agent 1's exploration agent flagged `jax.numpy.ndarray.at[:,:,idx].add()` as not accumulating duplicate indices. This is incorrect: JAX `.at[].add()` does correctly accumulate for duplicate indices (unlike `.at[].set()` which is non-deterministic). Verified by reading the JAX documentation. Not a bug.
- **Energy conservation bound in test_level3_energy_bound**: The existing bound `P_abs <= T0 * area * power` is technically too tight because Fresnel T_avg can exceed T0 near the Brewster angle (measured: T_avg_max/T0 = 1.056 at mu=0.30). However, the test has never failed in practice because the integral over all angles dampens the Brewster peak. Left as-is since it hasn't caused issues.
- **ECBF bisection "unbounded" loop**: The exploration agent flagged the lambda doubling in ecbf.py as potentially unbounded. It already has a `lam_high > 1e20` break and `_bisect` has `maxiter=200`. Already well-handled.

### Issues discovered

- **Fresnel T_avg > T0 at Brewster angle**: T_avg(mu=0.30) = 0.569 > T0 = 0.539 for skin at 28 GHz. This is physically correct (TM transmission enhanced at Brewster angle) but means the level 2 energy conservation bound `P_abs <= T0 * area * power` is not a strict mathematical bound for level 3. Robin should be aware if the bound matters for formal proofs.
- **Level 5 uses raw curvature_H (can be negative) while spatial.py floors to max(H, 0)**. This is an inconsistency between the legacy level API and the mode-based API for the curvature correction term. May be intentional (level 5 allows concave curvature effects) but worth verifying against the monograph.
