- [2026-04-11] feature-agent: Fixed Sentry #394 and #393. (1) GLB phantoms (boy_6y, girl_8y, adult_male, adult_female) were not served by `/api/body` because `_preload_bodies` only loaded STL files. MIMO dosimetry hook calls `fetchBody()` for all phantom types, so requesting a GLB-only phantom returned 404. Fix: extended `_preload_bodies` to discover GLB files in `data/phantoms/` and load them via `GltfSkeleton.pose_to_body()` into the same body cache. Fixes #394. (2) When antenna position coincides with body center (distance < 1e-6), `compute_dosimetry` generated a zero `k_hat` vector (dividing [0,0,0] by clamped distance 1.0), which caused `PropagationPaths.from_powers` to raise `ValueError: k_hat rows must have positive norm`. Fix: use fallback direction [0,0,-1] when distance < 1e-6. Both single-antenna and multi-antenna code paths fixed. Fixes #393. All 2333 tests pass, lint clean.
